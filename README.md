# data-science-ml-portfolio
Portafolio de notebooks de Data Science, Machine Learning (Google Colab)

## Guia rapida

- `TALLER_01_PROCESO_EDA_PARA_DATASET_TITANIC.ipynb`:

 Flujo completo de EDA y preparacion de datos sobre Titanic, con tratamiento de valores faltantes, ingenieria de variables, codificacion y configuracion de modelos base de clasificacion (por ejemplo, Regresion Logistica y SVM) para predecir supervivencia.

- `TALLER_03_REGRESIÓN_CON_ARB_DESIC_RAM_FOREST_GB_XGB_LGB - PRECIO CASAS EN CALIFORNIA.ipynb`: 
 Taller comparativo de regresion con modelos basados en arboles (Decision Tree, Random Forest, Gradient Boosting, XGBoost y LightGBM) para estimar precios de vivienda, con enfoque en comparacion de desempeno y criterios de seleccion.

- `TALLER_04_REGRESION CON SVR - POLINOMICA - PRECIO CASAS DE CALIFORNIA.ipynb`: 
 Proyecto de regresion supervisada centrado en Support Vector Regression (SVR), con analisis exploratorio, manejo de outliers mediante IQR, division train/test y experimentacion con kernels para modelar precios de vivienda.

- `TALLER_10_ANÁLISIS_DE_DATOS-DESAFIO_CORRECCIÓN_DE_OUTLIERS.IPYNB`: 
 Desafio de analisis de datos enfocado en detectar y corregir outliers (superiores e inferiores) usando boxplots y reglas IQR, mostrando mejora de calidad de datos previa al modelado.
