# Teaching Materials

This folder contains **lecture slides, exercises, guided notebooks, and course modules** developed for university courses and professional workshops. The materials are designed to be accessible to students with different levels of prior experience — from beginners learning Python for the first time to advanced students applying deep learning to real-world problems.

All interactive notebooks run in **Google Colab** — no software installation required for students.

---

## Courses and Modules

| Material | Level | Description |
|---|---|---|
| `intro_to_machine_learning/` | Beginner–Intermediate | Full university module: slides, exercises, and guided Colab notebooks covering the fundamentals of ML |
| `python_for_data_science/` | Beginner | Hands-on workshop covering Python, pandas, matplotlib, and scikit-learn basics |
| `deep_learning_fundamentals/` | Intermediate | Module introducing neural networks, CNNs, and RNNs with practical Keras/PyTorch examples |
| `nlp_applied_course/` | Intermediate–Advanced | Applied NLP course: from text preprocessing to BERT fine-tuning |
| `data_visualisation_workshop/` | Beginner | Workshop on creating clear, impactful charts with matplotlib, seaborn, and Plotly |

---

## Structure of Each Module

Each course or workshop folder typically contains:

```
module-name/
├── README.md            # Overview of the module: objectives, prerequisites, schedule
├── slides/              # Lecture slides (PDF or link to presentation)
├── notebooks/           # Guided Colab notebooks (theory + exercises)
└── exercises/           # Stand-alone exercises with solutions
```

---

## How to Use These Materials

### For Students

1. Navigate to the module folder relevant to your course.
2. Open the notebook for the current session.
3. Click the **"Open in Colab"** badge to launch it directly in your browser.
4. Read through the explanations and run each cell step by step.
5. Complete the exercises at the end of each notebook.

### For Educators

You are welcome to adapt these materials for your own courses under the terms of the [MIT License](../LICENSE). A brief attribution to the original author is appreciated.

To customise a notebook, open it in Colab, make a copy (`File → Save a copy in Drive`), and edit as needed.
